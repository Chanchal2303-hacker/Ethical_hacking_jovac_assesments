# Ethical Hacking Lab Reports — JOVAC Program

Practical assignments from the JOVAC Ethical Hacking course, covering 
offensive security and network forensics.

## 📁 Contents
1. **Metasploitable 2 – Vulnerability Assessment & Exploitation**
   Nmap recon, Metasploit exploitation (vsftpd backdoor), default-cred 
   SSH/Telnet access, SMB/MySQL enumeration, Nikto web scan (27 findings).

2. **Wireshark PCAP Forensics – Assignment 2**
   TShark/Wireshark analysis of traffic.pcapng — 20 verified data points 
   on protocol stats, DNS/SMB/NBNS activity, MAC-vendor ID, and firewall 
   gateway identification.

## 🛠️ Tools
Kali Linux, Nmap, Metasploit, Nikto, smbclient, MySQL/psql clients, 
Wireshark, TShark

## ⚠️ Disclaimer
All work performed in isolated lab environments for academic purposes only.
